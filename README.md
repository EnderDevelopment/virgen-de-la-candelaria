# Minecraft Mod: Virgen de la Candelaria

Virgen de la Candelaria is a Fabric Minecraft mod that adds a craftable devotional medallion inspired by the Virgin of Candelaria. This Minecraft mod includes a Spanish item name, a crafting recipe, and an operator-only command to obtain the medallion.

## Install

1. Install Fabric Loader for Minecraft 1.21.1 and Java 21 or newer.
2. Install Fabric API for Minecraft 1.21.1.
3. Build the project with `./gradlew build`.
4. Place the generated mod JAR from `build/libs` into your Minecraft `mods` folder.
5. Launch Minecraft with the Fabric profile.

## Use

- Craft the Medalla de la Virgen de la Candelaria with two gold nuggets across the top row, a gold nugget, sunflower, and gold nugget across the middle row, and an iron nugget in the bottom-center slot.
- Add the medallion to your inventory with `/candelaria`. This command requires operator permission level 2.
